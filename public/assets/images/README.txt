Company crest / logo
====================

Save the Brigade crest (the BB anchor + GB flame lockup) in THIS folder as:

    logo.png        <- used for the navbar, homepage hero, login page,
                       admin sidebar and the browser tab icon

Any of these names/extensions work, checked in this order:
    logo.svg, logo.png, logo.webp, logo.jpg, logo.jpeg

Optional, for a sharper browser tab icon (a square crop works best here):

    favicon.png     (or favicon.svg / favicon.ico)

If no file is present the site falls back to a shield icon, and a logo
uploaded through Settings -> Company Logo overrides whatever is here.
Nothing else needs changing - the code picks the file up automatically.
